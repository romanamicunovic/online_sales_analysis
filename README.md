# Online Sales Analysis

Ovaj projekat demonstrira osnovne funkcionalnosti rada sa proizvodima i korpom koristeci Python i Git 

## Funkcionalnosti
- Dodavanje proizvoda u inventar
- Racunanje ukupne vrijednosti inventara
- Dodavanje proizvoda u korpu
- Racunanje ukupne vrijednosti korpe

## Struktura fajlova
- "main.py" - glavni program
- "product.py" - klasa za proizvod
- "product_manager.py" - upravljanje proizvodima
- "cart.py" - funkcionalnosti korpe
- ".gitignore" - fajl koji ignorise 'config.json' i slike

## Pokretanje
Program se pokrece komandom:
python main.py
